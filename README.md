One moment it's there, full bars, mid-sentence on a video call; the next it has vanished without a word, no goodbye, no explanation, leaving you staring at a frozen face while it pretends it was never connected at all.

## Run it

```sh
node main.ts
```

Writes the word to `/output/entry.txt`.
